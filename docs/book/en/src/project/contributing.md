# Contributing

Contributions are welcome: bug reports, scenarios for new applications, hooks for other languages, patterns, and documentation. The full guide is [`CONTRIBUTING.md`](https://github.com/AsyncNomad/CacheWitness/blob/main/CONTRIBUTING.md).

Most useful right now:

- **Case studies.** Try a pattern against an open-source application with a Redis cache and report what you found, including "it passed" (that is evidence too).
- **Hooks for other languages.** The [protocol](../reference/hook-protocol.md) is a few Redis commands; Python first.
- **Reports of `NOT_REACHED` you could not explain.** They usually point at a gap in the documentation or a missing diagnostic.

Security issues: see [`SECURITY.md`](https://github.com/AsyncNomad/CacheWitness/blob/main/SECURITY.md); please do not open a public issue.
