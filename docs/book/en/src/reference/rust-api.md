# Rust API

The runner is three crates. Their API documentation is generated by rustdoc:

| Crate | Purpose | Docs |
|---|---|---|
| `cawit` | the command line | [docs.rs/cawit](https://docs.rs/cawit) |
| `cawit-verify` | the engine: scenarios, patterns, steps, checks, runner | [docs.rs/cawit-verify](https://docs.rs/cawit-verify) |
| `cawit-resp` | minimal RESP2/RESP3 parser and async Redis client | [docs.rs/cawit-resp](https://docs.rs/cawit-resp) |

The documentation site also hosts the API docs for the current `main` branch under [`/api/`](https://asyncnomad.github.io/CacheWitness/api/cawit_verify/).

Build them locally:

```bash
cargo doc --workspace --no-deps --open
```

Embedding the runner:

```rust,ignore
use cawit_verify::{Scenario, runner::Options};

let scenario = Scenario::load("stale-set.yaml".as_ref())?;
let report = cawit_verify::run(&scenario, &Options::default(), |run| {
    println!("run {}: {:?}", run.run, run.outcome);
})
.await?;
std::process::exit(report.exit_code());
```

To add your own step kinds, checks, or patterns, see [Extending the Engine](../architecture/extending.md). The API may change in any 0.x release; the scenario format and the hook protocol are the compatibility surface.
