# 기여하기

버그 보고, 새 애플리케이션 시나리오, 다른 언어의 훅, 패턴, 문서 모두 환영합니다. 전체 안내는 [`CONTRIBUTING.md`](https://github.com/AsyncNomad/CacheWitness/blob/main/CONTRIBUTING.md)(영어)에 있습니다.

지금 가장 도움이 되는 것:

- **사례 연구.** Redis 캐시를 쓰는 오픈소스 애플리케이션에 패턴을 돌려 보고, "통과했다"는 결과까지 포함해 알려 주십시오(그것도 증거입니다).
- **다른 언어의 훅.** [프로토콜](../reference/hook-protocol.md)은 Redis 명령 몇 개입니다. Python이 먼저입니다.
- **설명하지 못한 `NOT_REACHED` 보고.** 대개 문서의 빈틈이나 빠진 진단을 가리킵니다.

보안 문제는 공개 이슈 대신 [`SECURITY.md`](https://github.com/AsyncNomad/CacheWitness/blob/main/SECURITY.md)를 보십시오.
