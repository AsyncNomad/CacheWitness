# 参与贡献

欢迎各种贡献：缺陷报告、新应用的场景、其他语言的钩子、模式以及文档。完整指南见 [`CONTRIBUTING.md`](https://github.com/AsyncNomad/CacheWitness/blob/main/CONTRIBUTING.md)（英文）。

目前最有帮助的是：

- **案例研究。** 在使用 Redis 缓存的开源应用上试用某个模式，并报告你的发现，包括"它通过了"（这同样是证据）。
- **其他语言的钩子。** [协议](../reference/hook-protocol.md)只是几个 Redis 命令；Python 优先。
- **你无法解释的 `NOT_REACHED` 报告。** 它们通常指向文档中的漏洞或缺失的诊断。

安全问题请参阅 [`SECURITY.md`](https://github.com/AsyncNomad/CacheWitness/blob/main/SECURITY.md)，请不要公开提交 issue。
