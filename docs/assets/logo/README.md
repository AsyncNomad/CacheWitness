# cawit logo

| File | Use |
|---|---|
| `cawit-mark.svg` | Symbol, on light backgrounds |
| `cawit-mark-dark.svg` | Symbol, on dark backgrounds |
| `cawit-mark-mono.svg` | Single colour; follows `currentColor`, the eye is cut out (labels, print) |
| `favicon.svg` | Favicon and app icon (black rounded square, larger eye) |
| `cawit-logo-light.svg` / `cawit-logo-dark.svg` | Symbol + wordmark + tagline |

Colours: ink `#141414`, accent (eye) `#E8463A`, recommended background `#F5F3EF`.
Typeface: Bricolage Grotesque 800 (wordmark) and 400 (tagline), Google Fonts, OFL.

The wordmark is stored as text, so environments without the typeface (including GitHub's image rendering) show a fallback font. For a fixed banner, convert the text to outlines in a design tool and replace the files.
